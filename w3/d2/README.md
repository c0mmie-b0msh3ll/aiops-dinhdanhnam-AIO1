# W3-D2 Chaos Engineering

This folder contains a complete experiment catalog, a local `chaos_runner.py`, the generated `chaos_results.json`, a saved scoreboard, the chaos report, and submission reflection. The refreshed `w3-d2-pack.zip` is a starter pack rather than a full Docker stack, so this submission uses the pack schema and a deterministic local harness to simulate the pipeline responses. To reproduce: from this folder run `python chaos_runner.py > chaos_scoreboard.txt`, then optionally score with the starter-pack `scripts/score_run.py`.
