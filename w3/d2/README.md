# W3-D2 Chaos Engineering

This folder contains a complete experiment catalog, a local `chaos_runner.py`, the generated `chaos_results.json`, a saved scoreboard, the chaos report, and submission reflection. The course page names `w3-d2-pack.zip`, but the expected public URL returned 404 during setup, so the runner is a deterministic local harness that follows the required experiment catalog and scoreboard format. To reproduce: from this folder run `python chaos_runner.py > chaos_scoreboard.txt`.
