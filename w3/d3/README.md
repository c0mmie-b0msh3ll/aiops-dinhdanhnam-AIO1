# W3-D3 Outage Reproduction, Postmortem, ADR, Cost Model

This folder contains a Cloudflare Regex 2019-style reproduction, captured timeline, observed alerts/RCA output, blameless postmortem, ADR, cost model, W3 platform spec, and reflection. The refreshed `w3-d3-pack.zip` now includes reproduction templates; this submission uses the Cloudflare regex template under `reproduction/` and keeps the captured timeline and pipeline observations in the top-level files. Run `python cost_model.py` to reproduce the ROI examples.
