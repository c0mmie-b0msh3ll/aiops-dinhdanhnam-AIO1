# W3-D3 Outage Reproduction, Postmortem, ADR, Cost Model

This folder contains a written reproduction of a Cloudflare Regex 2019-style outage, captured timeline, observed alerts/RCA output, blameless postmortem, ADR, cost model, W3 platform spec, and reflection. The course page names `w3-d3-pack.zip`, but the expected public URL returned 404 during setup, so these artifacts follow the published assignment schema without the missing Docker reproduction pack. Run `python cost_model.py` to reproduce the ROI examples.
